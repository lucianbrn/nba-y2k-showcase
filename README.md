# NBA Y2K Showcase

Public forever-updating site. One Y2K-era player per team, name-first headings in team fonts/colors, black stage, background/vignette/font change per player.

Update procedure: edit the source in Muse's workspace (nba-y2k-showcase/site), rebuild the single-file deploy/index.html with assets inlined, push to main — Vercel auto-deploys to the same address.
